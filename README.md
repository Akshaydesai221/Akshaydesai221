## 🚀 About me

I build tools that take the manual grind out of shipping software. My work sits close to the
developer: git automation, conflict resolution, installers and packaging, and small AI assists that
suggest rather than decide.

- 🛠️ Currently building **ReleasePilot**, a JavaFX desktop app that turns a release from days of
  manual cherry-picking into a guided flow, with first class support for Frappe and ERPNext teams.
- 📦 Also maintain **WorkTrackr**, a work tracking tool, and the one click installer projects for both.
- ☕ Interested in Java 21, JavaFX, JGit, Maven multi module design and provider agnostic AI integration.
- 🧩 I care about clean seams in a codebase. My favourite kind of refactor is the one that lets the UI
  stop caring which backend answered.
- 💬 Ask me about git internals, cherry-pick conflicts, or packaging a Java desktop app so users never
  have to install a JDK.

## 📌 Featured projects

### ✈️ ReleasePilot
A desktop release manager for teams that cherry-pick fixes between long lived branches. Compares two
branches, groups commits by story ID, cherry-picks in order, and stops on conflicts with a
side by side resolve screen. Works against a local clone or against GitHub by token, with no clone
needed for browsing. Includes a deterministic Frappe and ERPNext JSON merge resolver and an optional
AI merge suggestion that fills the editable pane only, so nothing is ever auto applied.

`Java 21` `JavaFX` `JGit` `Maven multi module` `Gemini`

[📥 Installers](https://github.com/Akshaydesai221/ReleasePilot-Installers)

### ⏱️ WorkTrackr
A work tracking tool with one click installers for Windows and Ubuntu, bundling its own Java runtime
so there is nothing else to install.

`Java` `Desktop` `InstallBuilder`

[📥 Installers](https://github.com/Akshaydesai221/WorkTrackr-Installers) ·
